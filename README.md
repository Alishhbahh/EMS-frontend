# 🏢 Employee Management System (EMS)

A modern Employee Management System frontend built with **React**, **Vite**, **Material UI**, **Ant Design**, and **Redux**. The application provides an intuitive interface for managing employees, attendance, leave requests, and authentication.

---

##  Features

- 🔐 Secure Authentication
- 👥 Employee Management
- 📅 Attendance Tracking
- 📝 Leave Management
- 📊 Dashboard
- 🔄 Infinite Scrolling
- 📱 Responsive User Interface
- ⚡ Fast performance with Vite

---

## Tech Stack

### Frontend

- React 18
- Vite
- JavaScript
- Material UI
- Ant Design
- Redux
- React Router DOM
- Axios
- React Toastify
- Moment.js

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Alishbahh/EMS-frontend.git
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

---

## Backend

This project is the frontend for an Employee Management System and communicates with a backend API for:

- User Authentication
- Employee Records
- Attendance
- Leave Requests

Ensure the backend server is running before starting the application.
